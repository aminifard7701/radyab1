# ردیاب خبر | MVP

نسخه‌ی اولیه‌ی قابل توسعه بر اساس سند «ردیاب خبر – معماری فنی و نقشه راه (اندروید)».

## امکانات فعلی
- اپ اندروید فارسی و راست‌چین با Kotlin و Jetpack Compose
- ورود متن یا لینک خبر و ارسال به بک‌اند
- انتخاب خودکار/دستی منابع (در MVP گزینه‌ها ثبت می‌شوند)
- ایجاد Job و نمایش پیشرفت با polling
- نمایش ادعاها با وضعیت تأییدشده/ردشده/مشکوک/نامشخص
- تولید گزارش PDF در بک‌اند و دانلود آن
- ذخیره‌ی تاریخچه‌ی ساده در Room
- بک‌اند FastAPI با ساختار Coordinator و عامل‌های مستقل
- Docker و GitHub Actions برای تست بک‌اند و ساخت APK

## نکته‌ی مهم درباره‌ی دقت
این مخزن یک MVP اجرایی است، نه سامانه‌ی راستی‌آزمایی قطعی. در حالت پیش‌فرض، تحلیل‌گر پایه صرفاً ادعاهای متنی را استخراج و نتیجه‌ی «نامشخص» تولید می‌کند؛ هیچ خبری بدون اتصال واقعی به منابع مستقل، مدل زبانی و سرویس جستجو نباید تأیید یا رد شود. نبود API رسمی برای جستجوی سراسری برخی شبکه‌های اجتماعی در سند معماری نیز تصریح شده است.

## اجرای بک‌اند محلی
```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
مستندات API: `http://localhost:8000/docs`

## اجرای اندروید
پوشه‌ی `android` را در Android Studio باز کنید و Gradle Sync بزنید. برای اجرای روی گوشی، آدرس سرور را در صفحه تنظیمات اپ وارد کنید. برای شبیه‌ساز اندروید، آدرس پیش‌فرض `http://10.0.2.2:8000/` است.

## ساخت APK با GitHub
مخزن را در GitHub ایجاد و فایل‌ها را آپلود کنید. سپس از مسیر **Actions** گردش‌کار `Build Android APK` را اجرا کنید. APK در بخش Artifacts قابل دریافت است. برای انتشار عمومی، از GitHub Releases استفاده کنید.

## تنظیمات و اسرار
کلیدهای مدل و جستجو را فقط در متغیرهای محیطی سرور قرار دهید؛ هرگز در APK قرار ندهید. نمونه در `backend/.env.example`.

## نقشه‌ی توسعه
1. پیاده‌سازی Provider واقعی مدل و مدیریت کلیدها
2. افزودن کانکتورهای RSS و موتورهای جستجو با رعایت شرایط استفاده
3. افزودن تحلیل تصویر (EXIF، perceptual hash، C2PA و آزمون‌های احتمالی)
4. آرشیو شواهد و هش SHA-256
5. حساب کاربری، سهمیه، اشتراک و همگام‌سازی
6. استقرار نمونه‌ی داخلی و بین‌المللی و آزمون واقعی دسترسی شبکه
